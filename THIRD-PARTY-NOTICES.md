# Third-party notices

Everything this game draws and plays is generated by code in this repository. The list below
is therefore short by design, and it is the complete set of files authored elsewhere that ship
inside the build.

## Flora — none

The game is **procedural-only for flora** (Świat 2.0, 2026-08-06): every tree, bush and
tuft of grass is generated by code in this repository. No third-party foliage meshes or
textures ship in the build, so there is nothing here to attribute.

## Font — SIL Open Font License 1.1

`assets/fonts/BarlowCondensed-Medium.ttf` — Copyright 2017 The Barlow Project Authors
(https://github.com/jpt/barlow). The full license text ships beside the font as
`assets/fonts/OFL-BarlowCondensed.txt`.

## Rust dependencies

Build-time crates are declared in `Cargo.toml` and vendored by cargo from crates.io under
their own licenses (predominantly MIT/Apache-2.0). They are not redistributed as sources in
this repository; a machine-generated dependency license report belongs with the first store
build (`docs/product-program.md` §4).
