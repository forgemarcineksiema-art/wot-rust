# T-54 Benchmark Vehicle

## Implemented Production Variant

- `T-54-3 obr. 1951`

This is the canonical Armored Vehicle Forge benchmark. It is the first vehicle that must be judged
module by module instead of treated as a broad family silhouette. `T-55A` remains in `VehicleKind`
for wire/test compatibility, but it is not in `VehicleKind::PLAYABLE`, not in the Forge reference
pack, and not in the review lineup.

## Benchmark Identity

- Low Soviet medium hull with named upper glacis, lower plate, lower tub, side sponsons, fenders,
  engine deck, and rear plate.
- Five large road wheels per side with separate hubs.
- Continuous track belt around the running gear, with a distinct front idler and rear drive
  sprocket.
- No return rollers.
- Rounded cast turret whose heavy front cheeks carry the front mass proud of the turret sides (the
  casting does not neck in at the front), with a recessed mantlet socket.
- A trim cast mantlet ("pig's head") covering the moving gun aperture, flanked by the front cheeks —
  not a wide slab spanning the whole front.
- 100 mm D-10T gun without a bore evacuator.

## Hybrid Production Path

The production T-54 is built through `vehicle_build::t54_description()` and selected by
`vehicle_forge::authoritative_baked_vehicle`; the older `vehicle_geometry` recipe is not a second
authoritative model. Hard hull armour, glacis, deck and fenders use `solid`; the cast turret shell,
cheeks and mantlet socket are a **cast loft** — a stack of designed horizontal stations skinned into
one watertight casting (`vehicle_build::t54_turret_loft`, kernel in the `loft` crate — renamed to
`cast_loft` in R1 of the procedural kernel program), which replaced the earlier metaball `sdf_mesh`
turret as of commit `2efa773`. SDF remains available for
other cast work (fluid unions, sockets), but the production turret shell is no longer `sdf_mesh`. The
barrel, mantlet, wheels, idler, sprocket and tracks use `revolve`. LOD0 is the clean
factory-condition garage asset, capped at 22,000 triangles with a 12,000-triangle cap for the cast
turret; battle LODs remain independently reduced.

A bake-time **ambient-contact pass** (R8 / Task 25) darkens `surface_shade` in the recesses a real
casting and welded hull show in ambient light — the turret-ring seam and undercut, the mantlet seat
in the embrasure, the running-gear/track recess under the sponson, and the glacis weld line. The
cavities are semantic `CavityBand`s derived from the same blueprint dimensions that drive the
geometry (`vehicle_build::t54_surface_bake`), applied to the merged submeshes at build time, so the
shading survives LOD and feeds the existing `surface_shade` render path with no renderer change. The
Forge manifest records the named signals and a config hash; the artifact `source_hash` already moves
with the resulting shade. Mud, rust, decals and camouflage stay runtime overlays.

## Data Sources And Gameplay Translation

The implemented values are practical gameplay specs grounded in public historical data, not a
museum-grade fire-control simulation. The Forge benchmark uses the T-54-3 obr. 1951 as the visual
target; later T-55/D-10T2S details do not define this silhouette.

Reference points:

- [T-54/T-55 overview](https://en.wikipedia.org/wiki/T-54/T-55): T-54 lineage, D-10 series gun,
  Soviet medium hull/turret family context.
- [Tanks Encyclopedia T-54-1 article](https://tanks-encyclopedia.com/coldwar/soviet/t-54-1-1947/):
  early T-54 technical and visual baseline.
- [Wikimedia Commons T-54/T-55 gallery](https://commons.wikimedia.org/wiki/T-54/T-55): photo
  reference for silhouette, turret mass, running gear, and stowage.

## Current Gameplay Spec

`T-54-3 obr. 1951`:

- Mass: 36,000 kg
- Engine: 390 kW V-54 class
- Max forward speed: 13.89 m/s
- Gun: 100 mm D-10T
- Armor model: 100 mm hull front, 80 mm hull side, 45 mm hull rear, 200 mm turret front

## Damage-ready benchmark

- The cast turret collision ring uses 24 deterministic sectors while the production visual loft
  keeps 64 azimuth segments; contact tests keep the ballistic and rendered surfaces aligned.
- Permanent channels carry entry/inner-exit geometry, local thickness, material, residual energy
  and a stable semantic surface in hull, turret or moving-mantlet space.
- Runtime damage meshes are per tank and per pose frame. They remove the pierced skin and add an
  open 16-segment steel tunnel without changing the shared Forge asset.
- The authored interior contains breech, turret drive, ammunition, engine, radio and suspension;
  through-flight hits are ordered physically rather than inferred from the armor-zone name.
- Thrown tracks expose a five-link gap at the replicated path position and close again on re-seat.

## Assets

Generated vehicle asset:

```text
assets/vehicles/t54_1951.vehicle.json
```

Regenerate it with:

```powershell
cargo run -p tools -- generate-vehicle --vehicle t54-1951 --output assets/vehicles/t54_1951.vehicle.json
```

Generate the Forge benchmark artifact with:

```powershell
cargo run -p tools -- forge-vehicle --vehicle t54-1951 --profile lod0 --out target/forge/t54_real_benchmark
```
