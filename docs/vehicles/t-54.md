# T-54 Benchmark Vehicle

## Implemented Production Variant

- `T-54-3 obr. 1951`

This is the canonical Armored Vehicle Forge benchmark. It is the first vehicle that must be judged
module by module instead of treated as a broad family silhouette. `T-55A` remains in `VehicleKind`
for wire/test compatibility, but it is not in `VehicleKind::PLAYABLE`, not in the Forge reference
pack, and not in the review lineup.

## Benchmark Identity

- Low Soviet medium hull with named upper glacis, lower plate, lower tub, side sponsons, fenders,
  engine deck, and rear plate.
- Five large road wheels per side with separate hubs.
- Continuous track belt around the running gear, with a distinct front idler and rear drive
  sprocket.
- No return rollers.
- Rounded cast turret with front cheek mass and a recessed mantlet socket.
- Low, wide moving mantlet embedded in the turret front.
- 100 mm D-10T gun without a bore evacuator.

## Hybrid Production Path

The production T-54 is built through `vehicle_build::t54_description()` and selected by
`vehicle_forge::authoritative_baked_vehicle`; the older `vehicle_geometry` recipe is not a second
authoritative model. Hard hull armour, glacis, deck and fenders use `solid`; the cast turret shell,
cheeks and mantlet socket use `sdf_mesh`; the barrel, mantlet, wheels, idler, sprocket and tracks
use `revolve`. LOD0 is the clean factory-condition garage asset, capped at 22,000 triangles with a
12,000-triangle cap for the cast turret; battle LODs remain independently reduced.

## Data Sources And Gameplay Translation

The implemented values are practical gameplay specs grounded in public historical data, not a
museum-grade fire-control simulation. The Forge benchmark uses the T-54-3 obr. 1951 as the visual
target; later T-55/D-10T2S details do not define this silhouette.

Reference points:

- [T-54/T-55 overview](https://en.wikipedia.org/wiki/T-54/T-55): T-54 lineage, D-10 series gun,
  Soviet medium hull/turret family context.
- [Tanks Encyclopedia T-54-1 article](https://tanks-encyclopedia.com/coldwar/soviet/t-54-1-1947/):
  early T-54 technical and visual baseline.
- [Wikimedia Commons T-54/T-55 gallery](https://commons.wikimedia.org/wiki/T-54/T-55): photo
  reference for silhouette, turret mass, running gear, and stowage.

## Current Gameplay Spec

`T-54-3 obr. 1951`:

- Mass: 36,000 kg
- Engine: 390 kW V-54 class
- Max forward speed: 13.89 m/s
- Gun: 100 mm D-10T
- Armor model: 100 mm hull front, 80 mm hull side, 45 mm hull rear, 200 mm turret front

## Assets

Generated vehicle asset:

```text
assets/vehicles/t54_1951.vehicle.json
```

Regenerate it with:

```powershell
cargo run -p tools -- generate-vehicle --vehicle t54-1951 --output assets/vehicles/t54_1951.vehicle.json
```

Generate the Forge benchmark artifact with:

```powershell
cargo run -p tools -- forge-vehicle --vehicle t54-1951 --profile lod0 --out target/forge/t54_real_benchmark
```
