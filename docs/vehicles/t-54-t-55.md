# T-54/T-55 Legacy Compatibility Note

This file is kept for old references. The active Forge benchmark is
[T-54-3 obr. 1951](t-54.md), not a T-54/T-55 family.

`T-55A` remains implemented as a legacy-compatible `VehicleKind` because enum order is wire
identity. It may still appear in low-level compatibility tests and generated legacy specs, but it
is not part of `VehicleKind::PLAYABLE`, not a production garage vehicle, not a Forge
`ReferencePack`, and not a benchmark/review lineup entry.

Generate current production T-54 data with:

```powershell
cargo run -p tools -- generate-vehicle --vehicle t54-1951 --output assets/vehicles/t54_1951.vehicle.json
```
