# T-54/T-55 Vehicle Family

## Implemented Variants

- `T-54-3 obr. 1951`
- `T-55A`

The client default player tank is `T-55A`. The current server smoke bot uses `T-54-3 obr. 1951`, which gives both family entries immediate coverage in runtime composition.

## Data Sources And Gameplay Translation

The implemented values are practical gameplay specs grounded in public historical data, not a museum-grade fire-control simulation.

Reference points:

- [T-54/T-55 overview](https://en.wikipedia.org/wiki/T-54/T-55): T-54B/T-55 lineage, D-10 series gun, T-55 V-55 engine at 581 hp / 433 kW, 45-round ammunition increase, 200 mm class turret front notes.
- [T-55 Main Battle Tank, Tank Encyclopedia](https://tank-afv.com/coldwar/ussr/T-55.php): 36 t combat weight, V-55 581 hp / 433 kW, 55 km/h top speed, 100 mm D-10T2 gun family.

## Current Gameplay Specs

`T-54-3 obr. 1951`:

- Mass: 36,000 kg
- Engine: 390 kW V-54 class
- Max forward speed: 13.89 m/s
- Gun: 100 mm D-10T
- Armor model: 100 mm hull front, 80 mm hull side, 45 mm hull rear, 200 mm turret front

`T-55A`:

- Mass: 36,000 kg
- Engine: 433 kW V-55 class
- Max forward speed: 15.28 m/s
- Gun: 100 mm D-10T2S
- Armor model: 100 mm hull front, 80 mm hull side, 45 mm hull rear, 200 mm turret front

## Assets

Generated vehicle assets:

```text
assets/vehicles/t54_1951.vehicle.json
assets/vehicles/t55a.vehicle.json
```

Regenerate them with:

```powershell
cargo run -p tools -- generate-vehicle --vehicle t54-1951 --output assets/vehicles/t54_1951.vehicle.json
cargo run -p tools -- generate-vehicle --vehicle t55a --output assets/vehicles/t55a.vehicle.json
```
