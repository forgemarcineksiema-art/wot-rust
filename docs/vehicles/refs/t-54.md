# T-54 obr. 1951 — reference register

What we check the model against, where it lives, and how far each source can be trusted.

**No image files here, and that is deliberate.** The useful references for this vehicle are a
Wargaming render, a Wargaming icon, a Gaijin screenshot and a line drawing of unclear provenance.
The repo ships CC0 assets only and a commit to a public remote is distribution, so this register
carries links, provenance and the MEASURED features instead of the pixels. Anything that becomes a
locked number belongs in `docs/vehicles/t-54.md` with its source; this file is the shortlist of
what to open when a shape is in doubt.

## The registry

|---|---|---|---|---|

Fittings: medium** (line art loses casting detail) | Scaling the bake against the 9.00 m over-gun length; the plan view is the only source that shows the roof furniture laid out flat |
| R2 | [Wikimedia: T-54, NVA collection Dresden](https://commons.wikimedia.org/wiki/Category:T-54_tanks) | A real vehicle, real paint, real weathering | **High for material and colour**, medium for variant (museum vehicles get rebuilt) | Paint value, how the running gear reads in daylight, hull fitting shapes |
| R3 | Wargaming render, T-54 obr. 1951 (game asset) | Fitting-by-fitting layout of the 1951 turret | **Medium**: a game artist's reading, not a document — but a well-researched one | Where things sit relative to each other; the cupola vision blocks and hatch bolt rings are clearest here |
| R4 | Wargaming vehicle icon (game asset) | Clean side silhouette | Medium | Silhouette proportions at a glance |
| R5 | War Thunder screenshot, T-54 (game asset) | Running gear and track in daylight | **Medium**, and only for the two features below | Wheel-disc colour; top-run sag under load |

Sources 3–5 are other studios' interpretations. They are useful for *where a thing is*, never for
*what a number is* — numbers come from `docs/vehicles/t-54.md` and its cited documents. Treating a
competitor's model as a dimension source is how a clone happens, and the roster forbids clones.

## What the register settled (2026-08-10)

Read against the shipped bake. Each row is either already fixed, or a live defect with a home in
the audit.

|---|---|---|---|

## How to use this against the bake

`cargo run -p tools -- outline-overlay --vehicle t54_1951` (Forge 2.0 K0) writes one PNG per
view to `target/forge/outlines/`: grey where the bake and the reference outline agree, red where
the bake stands proud of the outline, blue where the outline has metal the bake does not, with
the IoU per view and what a 10 cm slide does to it. The outline lives in
`crates/vehicle/vehicle_forge/outlines/t54_1951.outline.ron`; its turret, gear ends and furniture
are placed from the blueprint until R1 is traced over these images — that tracing is what flips a
view from `Target` to `Locked`.

`cargo run -p tools -- export-mesh --vehicle t54-1951` writes OBJ+MTL; load it beside R1 in
Blender, scale on the 9.00 m over-gun length (high confidence, six independent sources) and
compare the side view. The lower-front-plate error is obvious by eye in that overlay in seconds —
it was found instead by deriving the plate normal from two constants in `t54_hybrid.rs`, which is
the slow way to see a wedge that is 18 degrees off.
