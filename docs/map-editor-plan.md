# Map Builder & Editor — Plan

Goal: maps as DATA (a RON blueprint per map), a deterministic compiler both ends of the
wire trust, and an interactive editor that is a pleasure to author in — everything it does
writes ops into the document, so undo is an op stack and a diff stays readable.

Design lineage: the project's own forge loop (`vehicle_forge`/`world_forge`: blueprint →
deterministic bake → golden hash → review report), World Machine / UE Landmass for
structural terrain ops, and the WoT map anatomy (`TerrainMapPlan`'s 12 layers).

## Hard rules

1. Blueprint is the source of truth; code holds the op vocabulary, never a map's content.
2. Compilation is pure and deterministic; the map never crosses the wire (`MapId` +
   content hash only); `MapId` variants are append-only.
3. Every brush stroke is a quantized op in the document — no hidden editor state.
4. A broken map is a build-time bug: the contract report blocks shipping (Error), and the
   golden hash makes every map change a reviewed change.
5. The editor reuses the game's render path and render-only/runtime split: presentation
   (scenery, roads, weather) never changes gameplay truth; cover/spawns do — hence goldens.
